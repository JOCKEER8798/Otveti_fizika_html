1. lim f(x) = A (при x → x₀)

Коши: ∀ ε > 0 ∃ δ > 0 ∀ x: 0 < |x - x₀| < δ ⇒ |f(x) - A| < ε

Словами: Для любого эпсилон больше нуля, существует дельта больше нуля, такая что для всех икс, если икс отстоит от икс нулевого на расстояние меньше дельта (но не равно ему), то значение функции отстоит от А на расстояние меньше эпсилон.

Часть 2. Теоретические вопросы (1-37)

1-4. Логическая символика, множества, грани

Логика: ∀ (для всех), ∃ (существует), ⇒ (следует), ⇔ (эквивалентно). Отрицание: ¬(∀x P(x)) = ∃x ¬P(x).

Грани: Множество ограничено сверху, если ∃M: ∀x∈X, x ≤ M. M — верхняя грань. Sup X — наименьшая из верхних граней (точная верхняя грань). Inf X — наибольшая из нижних граней.

Эквивалентные определения Sup: 1) ∀x∈X, x ≤ S и ∀ε>0 ∃x∈X: x > S-ε. 2) S - верхняя грань, и любая меньшая не является верхней гранью.

5. Теорема о существовании точной верхней грани

Любое непустое ограниченное сверху числовое множество имеет точную верхнюю грань (sup). Аналогично для inf.

6. Определение предела последовательности. Единственность.

Число a — предел последовательности {xₙ}, если ∀ε>0 ∃N: ∀n>N ⇒ |xₙ - a| < ε.

Предел единственен (доказывается от противного: если два предела a и b, берем ε = |a-b|/2 и приходим к противоречию).

7-10. Свойства сходящихся последовательностей и милиционеры

7. Ограниченность: Сходящаяся последовательность ограничена.

8. Сохранение знака: Если lim xₙ = a > 0, то начиная с некоторого номера xₙ > 0.

9. Переход к неравенству: Если xₙ ≥ yₙ и оба предела существуют, то lim xₙ ≥ lim yₙ.

10. Лемма о двух милиционерах: Если xₙ ≤ zₙ ≤ yₙ и lim xₙ = lim yₙ = a, то lim zₙ = a.

11-13. Бесконечно малые (БМ) и большие (ББ) последовательности

БМ: lim xₙ = 0. Связь: lim xₙ = a ⇔ xₙ = a + αₙ, где αₙ — БМ.

ББ: ∀M>0 ∃N: ∀n>N |xₙ| > M. Связь: если xₙ — ББ, то 1/xₙ — БМ.

Свойства: Сумма БМ — БМ. Произведение БМ на ограниченную — БМ. Произведение двух БМ — БМ.

Теоремы о пределах: Предел суммы/произведения/частного равен сумме/произведению/частному пределов (если знаменатель не ноль).

14-18. Монотонные, вложенные, Больцано-Вейерштрасс, Коши

14. Вейерштрасс: Всякая монотонная ограниченная последовательность сходится.

15. Число e: lim (1 + 1/n)ⁿ = e. (Бином Ньютона используется для доказательства сходимости).

16. Вложенные отрезки: Если [aₙ, bₙ] вложены и их длины → 0, то ∃! точка c, принадлежащая всем отрезкам.

17. Больцано-Вейерштрасс: Из любой ограниченной последовательности можно выделить сходящуюся подпоследовательность.

18. Критерий Коши (для послед.): xₙ сходится ⇔ ∀ε>0 ∃N: ∀n,m>N |xₙ - xₘ| < ε (фундаментальная).

19-21. Предел функции, свойства, арифметика

19: Определения по Коши и Гейне (см. Часть 1). Они эквивалентны. Пример без предела: функция Дирихле. С пределом: f(x) = x в точке 0.

20: Единственность, локальная ограниченность, сохранение знака (аналогично последовательностям).

21: Предел суммы, произведения, частного. Доказывается через определения Коши (эпсилон-дельта) или Гейне (сведение к последовательностям).

22-24. Непрерывность функции

22: f непрерывна в точке x₀, если lim(x→x₀) f(x) = f(x₀). Или: Δy → 0 при Δx → 0. Свойства: арифметические операции сохраняют непрерывность.

23: Композиция непрерывных функций непрерывна.

24: Все основные элементарные функции (степенные, показательные, логарифмические, тригонометрические) непрерывны на своих областях определения.

25-27. Замечательные пределы и Критерий Коши (для функций)

25. Первый замечательный: lim(x→0) sin(x)/x = 1.

26. Второй замечательный: lim(x→∞) (1 + 1/x)ˣ = e.

27. Критерий Коши: f имеет предел в x₀ ⇔ ∀ε>0 ∃δ>0: ∀x',x'' (0<|x'-x₀|<δ и 0<|x''-x₀|<δ) ⇒ |f(x') - f(x'')| < ε.

28-29. Эквивалентные функции (о-малое)

БМ на бесконечности: lim f(x) = 0 при x→∞.

о-малое: α(x) = o(β(x)) при x→x₀, если lim α/β = 0.

Эквивалентность: α ~ β, если lim α/β = 1. (Замена в пределах: sin x ~ x, ln(1+x) ~ x, eˣ-1 ~ x, 1-cos x ~ x²/2).

30-34. Теоремы о непрерывных функциях на отрезке

30 (Вейерштрасс 1): Непрерывная на отрезке функция ограничена на нем.

31 (Вейерштрасс 2): Непрерывная на отрезке функция достигает своего максимума и минимума.

32 (Больцано-Коши 1): Если f(a) и f(b) разных знаков, то ∃c∈(a,b): f(c) = 0.

33 (Больцано-Коши 2): Непрерывная функция принимает все промежуточные значения.

34. Обратная функция: Если f строго монотонна и непрерывна на [a,b], то обратная f⁻¹ существует, непрерывна и монотонна.

35-37. Разрывы и Равномерная непрерывность

35. Разрывы: 1 рода (пределы слева и справа конечны, но не равны — скачок), 2 рода (хотя бы один предел бесконечен или не существует).

36. Модуль непрерывности: ω(δ) = sup |f(x) - f(y)| для |x-y| < δ. Равномерная непрерывность: ∀ε>0 ∃δ>0 ∀x,y: |x-y|<δ ⇒ |f(x)-f(y)|<ε.

37 (Кантор): Функция, непрерывная на отрезке, равномерно непрерывна на нем.

Часть 3. Задачи и доказательства (1-24)

1-7. Свойства Sup и Inf (доказательства)

1. sup(X+Y) = sup X + sup Y. Пусть S = sup X + sup Y. Для любых x∈X, y∈Y: x+y ≤ S. Значит S - верхняя грань. Для любого ε>0: ∃x>sup X - ε/2, ∃y>sup Y - ε/2. Тогда x+y > S - ε. Значит S — точная верхняя грань.

3. sup(-X) = -inf X. Пусть m = inf X. Тогда ∀x∈X: x ≥ m ⇒ -x ≤ -m. Значит -m — верхняя грань для -X. Для любого ε>0 ∃x < m + ε ⇒ -x > -m - ε. Значит -m = sup(-X).

5. Если X ≤ Y, то sup X ≤ sup Y. По определению, любой элемент Y больше любого элемента X. sup Y — верхняя грань для Y, значит она больше или равна любому x∈X. Следовательно sup Y — верхняя грань X. А sup X — наименьшая верхняя грань, значит sup X ≤ sup Y.

8-11. Свойства последовательностей

8-9. Предельные точки: а) Наличие бесконечного числа членов в окрестности не гарантирует сходимость (пример: 1, -1, 1, -1...). б) Последовательность ограничена (т.к. все члены в окрестности, а вне её конечное число).

10. Бесконечно большая последовательность не имеет конечных предельных точек (может иметь ∞ как предельную точку).

11. Одна предельная точка не гарантирует сходимость (пример: 1, 1/2, 1, 1/3, 1, 1/4... предел 1, но сходимости нет).

12-13. Доказательство отсутствия предела

12. xₙ = 1 + 1/2 + ... + 1/n (Гармонический ряд). Используем критерий Коши: |x₂ₙ - xₙ| = 1/(n+1) + ... + 1/2n > n * (1/2n) = 1/2. Условие Коши не выполняется (нельзя сделать меньше любого ε).

13. Функция Дирихле. В любой окрестности точки x есть как рациональные, так и иррациональные числа. Поэтому предел не существует ни в одной точке.

14-19. Непрерывность и пределы функций

14. f(x) = cos(1/x). Возьмем xₙ = 1/(2πn) → 0, f(xₙ) = 1. Возьмем yₙ = 1/(π + 2πn) → 0, f(yₙ) = -1. Пределы разные, значит предела нет.

15. По определению непрерывности: Подставляем x₀+Δx в функцию, вычитаем f(x₀), показываем что разность стремится к 0 при Δx → 0.

19. lim sin(α(x))/α(x). Так как α(x)→0, можно сделать замену t = α(x), тогда lim(t→0) sin(t)/t = 1 (первый замечательный).

20-24. О-малые, Монотонность, Модуль непрерывности

20. lim (1+α(x))^(1/α(x)). Замена t = 1/α(x). При α→0, t→∞. Получаем второй замечательный предел (1+1/t)^t = e.

21. Монотонная неограниченная последовательность. Пусть возрастает. Так как не ограничена сверху, ∀M ∃N: x_N > M. Тогда ∀n>N, x_n ≥ x_N > M. Значит предел +∞.

23-24. Модуль непрерывности. ω(δ) = sup_{|x-y|<δ} |f(x) - f(y)|. Для sin(1/x) на (0,1) ω(δ) = 2 (или 0, в зависимости от δ). Для x² на [-2, 1] функция Липшицева с константой 4, значит ω(δ) = 4δ.
